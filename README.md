# Coffeerence

**coffee + coherence** — 淹れ方に一貫性を持たせるための記録帳。

コーヒーの**淹れ方と味を記録**し、登録したレシピに合わせて**注ぐタイミングを
チーンと知らせる**タイマーを持ったアプリです。

ビルド工程はありません。`index.html` を開けば動きます。

**記録はこの端末の中にだけ置きます。**アカウントも、送信先のサーバもありません。
淹れた記録がどこかへ流れていくことはなく、登録も要りません（データは
ブラウザの IndexedDB に入ります）。持ち出したいときは、設定からCSVで
書き出してください。

## できること

### 淹れる（タイマー）
- レシピを選ぶと、手順の時刻に**チャイムが鳴り**、「何投目か」「合計何gまで注ぐか」を表示します
- 3秒前の**予告音**と、**読み上げ**（「2投目。160グラムまで」）
- 残り秒数、進み具合のリング、注いだ湯量のバー、手順の一覧
- その場で**粉量を増減**すると、湯量も各手順の目標量も一緒に伸び縮みします
- 淹れ終わったらそのまま味の記録へ（器具・分量・抽出時間は引き継がれます）
- レシピなしで測るだけの計測もできます（「注いだ」を押した回数を残せます）

チャイムは音声ファイルを持たず、その場で合成しています。オフラインでも鳴り、
読み込み待ちで遅れることもありません。鳴る時刻は Web Audio の時計へ**先に予約**
してあるので、画面を消していても・別のアプリを見ていても、時間どおりに鳴ります。

### 記録する
- 豆（銘柄・焙煎所・焙煎度）、器具、挽き目、ミルの目盛り、粉/湯/湯温/時間、比率
- 味は5つの軸（酸味・甘み・苦味・コク・香り）とレーダー、5段階の総合評価
- 風味のことば（タグ）、感想、「次はこうする」
- 月ごとの一覧、豆やメモでの検索、★4以上・今月での絞り込み
- 過去の記録から、豆や焙煎所の候補が入力欄に出ます

### レシピ
- 手順は「開始から何秒に、何をして、合計何gまで注ぐか」で書きます
- 最初から5つ入っています（4:6メソッド／V60 ふつうの一杯／フレンチプレス／
  エアロプレス／アイス）。消しても設定から入れ直せます

### 持ち出す（CSV）
- **記録** … 1杯が1行。日時・豆・焙煎所・焙煎度・器具・挽き目・ミル・粉・湯・比率・
  湯温・抽出時間（`2:45` と秒数の両方）・レシピ・総合評価・5つの味・風味・
  感想・次はこうする
- **レシピ** … 1つが1行。手順は `0:00 蒸らし 45g / 0:30 2投目 150g` の形で1欄に畳みます
- Excel が化けないよう BOM 付きUTF-8、改行はCRLF（RFC 4180）に沿っています

### そのほか
- 明るい／暗いテーマ、ホーム画面に追加して全画面で使えます（PWA）
- オフラインでも開けます（Service Worker）

## 動かす

```sh
# この場で見る
python3 -m http.server 8000
# → http://localhost:8000
```

Service Worker は `file://` では動かないので、簡易サーバ越しに開いてください
（記録やタイマーは `file://` でも動きます）。

### 公開する（GitHub Pages）

リポジトリの **Settings → Pages → Build and deployment** で
Source に `Deploy from a branch`、Branch に `main` / `/ (root)` を選ぶと、
`https://<ユーザー名>.github.io/coffee/` で公開されます。公開しても、記録は
見る人それぞれの端末に残るだけで、どこにも集まりません。

## ロゴの下の番号

ホームのロゴの下に出る `#003` は、`main` へマージした回数です。
`app.js` 冒頭の `MERGE_COUNT` に持たせているので、マージのたびに1つ増やします。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み（8つの画面と下タブ） |
| `app.js` | 全部の処理。先頭のコメントに章立てがあります |
| `styles.css` | 見た目。色は `:root` の変数にまとめてあります（EnGoloydと同じ配色） |
| `sw.js` | オフラインで開くためのキャッシュ |
